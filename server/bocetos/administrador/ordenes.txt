 Nota de Diseño: El campo id_usuario INT NULL en la tabla ordenes
1. ¿Por qué el campo permite NULL (ON DELETE SET NULL)?
Se diseña como un campo opcional (NULL) por un motivo fundamental de integridad contable y cumplimiento legal (derecho al olvido / privacidad):

Si un usuario registrado realiza una compra y tiempo después decide eliminar su cuenta de la plataforma, el sistema no debe romper ni borrar el historial de ventas.

Gracias a la regla ON DELETE SET NULL, al borrarse el usuario de la tabla usuarios, su registro de la orden permanece intacto en la base de datos para fines contables y de auditoría, pasando el id_usuario a valor NULL.
